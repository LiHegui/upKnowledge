一、React 核心 ​

1. 组件与通信 ​

  • 类组件 vs 函数组件的区别，为什么函数组件是主流？

    A： 核心区别在于心智模型和代码组织方式。

    1. 声明式 vs 命令式：函数组件是纯函数，props 进来、JSX 出去，没有 this、没有实例。每次 render 就是一次快照调用，闭包捕获固定值，状态不易失控。类组件用 this.state 读的是「最新引用」，异步回调里容易出现同一轮 render 中读到过期 state 的反直觉问题。

    2. 逻辑复用方式不同：函数组件通过 Hooks + 自定义 Hook 抽离逻辑，组合自然、tree-shakable、无嵌套。类组件只能用 HOC / render props，必然导致 wrapper hell。

    3. 生命周期治理：函数组件用 useEffect 按关注点（concern）组织，相关逻辑放在一个 effect 里；类组件被迫按时间轴分散到 componentDidMount / componentDidUpdate / componentWillUnmount，维护成本高。

    总结：Hooks 使函数组件具备了比类组件更好的组合能力、更低的心智负担和更简洁的代码结构，这是它成为主流的技术底因。自 React 16.8 起，官方文档也将函数组件定位为首选方案。目前新项目默认用函数组件，面试也默认考察函数组件的写法。

  • state 和 props 的区别，单向数据流怎么理解

  • 组件通信方式（父子 props、兄弟状态提升、跨层 Context、全局 Redux/Zustand）

  • Context 的局限性和优化方案（按频率拆分、memo 防火墙）

4. 性能优化 ​

  • React 性能优化策略总览（测量 → 资源 → 渲染 → 并发 → SSR）
